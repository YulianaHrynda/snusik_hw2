# snusik_hw2 — Airbnb price lakehouse (US Northeast)

Group Assignment 2, team **Snusik**.

| Item | Value |
|---|---|
| Region | **US Northeast** (currency: USD) |
| City A (training) | **Boston, MA** — snapshot `2026-09-19` (4,368 listings) |
| City B (training) | **Jersey City, NJ** — snapshot `2026-09-21` (2,330 listings) |
| City C (new client, hold-out) | **New York City, NY** — snapshot `2026-09-14` (29,918 listings) |

Data: [Inside Airbnb](https://insideairbnb.com/get-the-data/) (CC BY 4.0), the detailed
`listings.csv.gz` of the latest snapshot of every city (pinned in
[`src/airbnb/cities.json`](src/airbnb/cities.json)).

**Why New York as city C:** it is the region's largest and most expensive market and, unlike
Boston and Jersey City, is governed by Local Law 18 (strict short-term-rental registration), so
it is the most realistic stress test of whether a model built on two mid-size markets transfers.

**Presentation:** [`presentation/presentation.pdf`](presentation/presentation.pdf)
(source: [`presentation/slides.html`](presentation/slides.html)).

## Results at a glance

MAE in USD per night on held-out test listings (20% hash split per city, fixed before any model).

| | Boston + Jersey City | New York City |
|---|---:|---:|
| Baseline — median A+B training price for the same room type × guests | \$124.67 | \$164.16 |
| Model `v1` — end of week 1 (first, unchanged run on New York) | **\$73.63** | **\$143.16** |
| Model `v2` — after the city C changes, still trained on A + B only | \$76.13 | **\$114.70** |
| Reference: `v2` recipe retrained with New York's training split | — | \$87.58 |

The full story — what ran, what broke, every change classified as *pipeline fix* or *model change*,
and the gap explained — is in [`docs/city_c_report.md`](docs/city_c_report.md).

## Running it on Databricks (Free Edition)

```bash
databricks bundle validate
databricks bundle deploy                                   # jobs, notebooks, dashboard
databricks bundle run airbnb_train_price_model             # ETL for Boston + Jersey City, train v2
databricks bundle run airbnb_train_price_model --params model_version=v1,feature_set=v1   # the week-1 model
databricks bundle run airbnb_onboard_city --params city=new-york-city,model_version=v1     # first run
databricks bundle run airbnb_onboard_city --params city=new-york-city,model_version=v2
# then: run genie/01_document_gold_tables.py once, and
python genie/deploy_genie.py
```

If serverless compute cannot reach the internet, land the files first with
`scripts/upload_raw.sh <city>`; the ingest task uses a file that is already in the volume.

Adding a city: one entry in [`src/airbnb/cities.json`](src/airbnb/cities.json), then
`airbnb_onboard_city --params city=<key>`.

## Running it locally

The same notebooks run unchanged on local Spark 4 + Delta (Python 3.12, Java 17):

```bash

.venv/bin/python scripts/run_local.py onboard --city new-york-city --model-version v1

```

## Running on Databricks — status

Everything was first developed and run locally (`scripts/run_local.py`) while the team's Free
Edition workspace was out of compute quota and then inactive. Once it was active again, the bundle
was deployed and **every job ran on Databricks serverless**:

* `airbnb_city_pipeline` for Boston, Jersey City and New York (Inside Airbnb downloaded from inside
  Databricks into the `airbnb_bronze.raw` volume);
* `airbnb_train_price_model` for `v1` (week 1), `v2` and the `v2_abc` reference;
* `airbnb_onboard_city` for New York with `v1` (first run) and `v2`;
* the AI/BI dashboard is published on the Serverless Starter Warehouse and all three pages were
  checked in the browser;
* the Genie space *Airbnb US Northeast — prices and price model (Snusik)* is created (id in
  [`genie/.space_id`](genie/.space_id)) and answers the example questions correctly
  ([`docs/genie.md`](docs/genie.md)).

The Databricks runs reproduce the local numbers; the small differences come from the scikit-learn
version of the serverless environment (and, for `v2`, CV picking the deeper of two variants that
were within \$0.10 of each other):

| Test MAE, USD | Local | Databricks |
|---|---:|---:|
| Baseline, Boston + Jersey City | 124.67 | 124.67 |
| `v1`, Boston + Jersey City | 73.63 | 73.69 |
| `v1`, New York (first run) | 143.16 | 144.19 |
| Baseline, New York | 164.16 | 164.16 |
| `v2`, Boston + Jersey City | 76.13 | 75.28 |
| `v2`, New York | 114.70 | 115.08 |
| `v2_abc` (reference), New York | 87.58 | 87.59 |

The reports, model cards and the presentation quote the local run; the dashboard and Genie show
the Databricks tables.
